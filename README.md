# 供应商全景查询

纯前端、离线可用的供应商全景查询页面（长城汽车集团供应链金融 · 保理侧）。

- **单家查询**：企业速览 / 启信慧眼画像 / 中登登记 / 供货同比 / 付款明细一站呈现
- **批量查询**：粘贴多个名称或编码出表格，一键导出 Excel(.xlsx)
- **改名兼容**：支持启信画像曾用名与统一信用代码命中，改名企业新旧名称都能查到
- **数据全部内嵌**：页面自包含，无 CDN、无后端，可离线双击打开

## 访问地址

GitHub Pages：`https://lekelin2046.github.io/supplier-panorama/`

## 数据口径

- 供货额：BSP 导出开票/交付供货口径（2025 全年 + 2026 上半年 + 2026 年 7 月）
- 付款额：各采购主体实际付款金额（与供货额口径不同，金额不一致属正常）
- 中登登记：以自有「批量中登查询」数据为准

## 文件说明

- `index.html`：可直接打开的查询页面（数据内嵌，约 15MB）
- 页面由 supplier-supply-dashboard 项目 `02-脚本/build_trend_html.py` 生成后发布
