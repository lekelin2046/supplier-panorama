# 供应商全景查询

单页自包含的供应商综合查询看板，纯前端、离线可用。输入供应商名称或编码，一站呈现五大板块：

- **企业速览**：供货板块、上年度供货额、省份城市、成立年份、资金背景、企业规模、注册资金、参保人数、科技认定、所属集团等关键信息色块，附中登登记情况汇总。
- **启信慧眼画像**：企业基本信息、联系方式、风险扫描（行政处罚、失信、被执行、司法涉诉等），覆盖 3400+ 家供应商。
- **中登登记信息**：应收账款质押 / 保理 / 融资租赁等 7 类登记数量及明细（默认折叠）。
- **供货信息**：2026 年 1–7 月供货额走势与月度同比对照（2025 vs 2026，默认折叠）。
- **付款明细**：分付款主体金额、走势与占比（明细默认折叠）。

## 使用

- **单家查询**：输入名称（支持模糊匹配），展开完整画像；曾用名企业新旧名均可命中。
- **批量查询**：粘贴多个名称/编码，表格呈现，可一键导出 Excel（.xlsx）。
- 数据全部内嵌，无 CDN 依赖，可直接离线打开 `index.html`。

## 数据口径

- 供货板块标签仅供参考，以付款明细主体为准。
- 供货额覆盖 2026 年 1–7 月及 2025 年同期；上年度供货额取 2025 全年。
- 中登数据来自批量中登查询，以页面标注的查询截止日为准。
